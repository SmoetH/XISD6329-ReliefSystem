# Disaster Relief Management System (XISD6329)

A comprehensive, multi-platform software solution designed to coordinate, track, and manage disaster relief operations, resource allocations, and real-time requests.

---

## 🛠 Project Architecture

This repository contains a full-stack solution split into three main modules:

* **ReliefSystem.API**: ASP.NET Core Web API backend handling data persistence, business logic, and endpoint services.
* **ReliefSystem.Web**: ASP.NET Core Web dashboard for administrative users, coordinators, and system managers.
* **ReliefSystem.Mobile**: Cross-platform mobile application interface for field responders and real-time updates.

---

## 🚀 Key Features

* **Resource Management:** Track incoming donations, medical supplies, and essential goods.
* **Relief Request Dispatch:** Streamlined logging and tracking of emergency assistance requests.
* **Role-Based Access:** Differential views and permissions for administrators, field workers, and coordinators.
* **RESTful Services:** Modular API endpoints connecting web and mobile client interfaces.
